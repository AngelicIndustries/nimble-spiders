* Renamed the mod to Nimble Spiders. The mod ID is now `nimble-spiders`, the package is `industries.angelic.nimblespiders`, and release jars are named NimbleSpiders.
* The config file moved to `config/nimble-spiders/nimble-spiders.cfg`. Settings from `config/spiderstpo/spiderstpo.cfg` are not migrated.
* Added climbing, pathfinding and AI support for AbyssalCraft Anti-Spiders.
* Added surface climbing for Invasion Mod spiders. Invasion's AI, nexus pathing, pounces, egg laying and fall rules are unchanged.
* Spiders now notice targets well above them, such as a player on a tower, and keep climbing toward a target they can't see while they still have a way to reach it.
* Fixed spiders spinning in place in water.
